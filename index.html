🧪 Unit Testing Practice Application

Learn to write unit tests with Jest

Welcome to the Unit Testing Demo!

This application is designed to help you practice writing unit tests using Jest. You'll be testing the functions in dataProcessor.js.

📋 Setup Instructions

Follow these steps to get started with Jest unit testing:

  1. 1. Initialize Node Environment

    Create a new Node.js project with default settings:

    npm init -y

    This creates a package.json file with default configuration.

  2. 2. Create Tests Directory

    Create a __tests__ folder for your test files:

    mkdir __tests__

    Jest automatically looks for test files in the __tests__ directory.

  3. 3. Write Unit Tests

    Create unit tests for the functions in dataProcessor.js:

    Create test files like __tests__/dataProcessor.test.js

    Test various scenarios including edge cases, valid inputs, and error conditions.

  4. 4. Run Your Tests

    Execute your tests using npm:

    npm test

    Make sure to install Jest first: npm install --save-dev jest

💡 Testing Tips

  • Write tests before implementing functions (Test-Driven Development)
  • Test both happy path and error scenarios
  • Use descriptive test names that explain what is being tested
  • Keep tests simple and focused on one thing at a time
  • Use describe() blocks to group related tests
